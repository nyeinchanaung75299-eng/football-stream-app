# V6.3 Fixture Picker

- Removed Highlights from the Admin dashboard.
- Added **Pick Football Fixtures**.
- Added **Create Match Manually** as a separate option.
- API list does not automatically publish every fixture.
- Admin ticks only the matches that should appear in the app.
- Multiple selected matches can be imported at once.
- Imported API team logos can be replaced later in **Edit Matches**.
- Manual matches and API matches can be mixed freely.
- Existing match/link Edit/Delete functionality remains.
- API-Football key is designed to live in a Supabase Edge Function secret, not inside the APK.
