# V5 Android 12 stability build

Target test phone: Android 12 / ColorOS 12.1.

- Viewer no longer uses Better Player.
- Native Android Media3 / ExoPlayer handles HLS and DASH.
- Authorized ClearKey DASH support remains available.
- Referer and Origin headers remain supported.
- WebView mode remains available.
- VPN/network errors show simple messages instead of raw stack traces.
- Java 21 release split-ABI build is retained.

Install app-arm64-v8a-release.apk on the test phone.
