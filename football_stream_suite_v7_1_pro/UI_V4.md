# V4 Modern UI

This version keeps the V3 release/split APK workflow and V2 stream features, while redesigning both apps.

## Added
- Light / Dark / System themes in both apps
- Theme preference is remembered on-device
- Cleaner Material 3 cards and spacing
- Modern green football visual identity
- Polished admin login and dashboard
- Cleaner live upload and stream-link forms
- Better live match cards in the user app
- Live badge, server count, improved team-logo layout
- Cleaner player screen and server selector
- Existing HLS / MPD / authorized ClearKey / Referer / Origin / WebView support retained
- Release + split-per-ABI GitHub Actions workflow retained

## Theme switch
Tap the theme icon in the top-right:
- System
- Light
- Dark
