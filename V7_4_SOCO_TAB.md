# V7.4 Soco source tab

Viewer home now has:
- Main Live: native Supabase-selected matches.
- Soco: in-app view of https://m.sutbongtv.com/match.html

On Android the Soco source opens inside an embedded WebView.
On Web it uses an iframe when the source permits embedding, with a button to open the source in a new browser tab.

This is a source-view integration. It does not copy or republish third-party stream URLs into Supabase.
