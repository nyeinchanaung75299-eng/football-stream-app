# Source support

Viewer tabs are Live, Live 2, Soco, YYZB, ColaTV, Fawa and Channels.
Live 2 reads the repository football catalogue independently of matches selected
for the main Live tab. Native source configurations stay behind the playback gateway.

YYZB mirrors the original website's football-room catalogue from `matches.json`.
It excludes other sports and does not combine the NCA Live or score schedules.
Arena Koora keeps original football fixtures visible before stream servers are published.

Repository copy actions are available only in Admin. Team images use the
operator-reachable relay; existing VPN and non-VPN playback routes are preserved.
HTTP/manifest reachability and decoded device playback remain separate checks.
